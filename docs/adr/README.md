# Architecture decision records

The design document (`docs/design/`) records the decisions made before implementation. ADRs record decisions made during implementation that change, refine or contradict it. Numbered, never edited after acceptance; a change is a new ADR that supersedes the old one.

Write an ADR when a PR would: add a dependency in a security-critical crate, change an on-disk or frontmatter contract, deviate from a numbered decision (D1 to D10) in the design, or resolve one of the open questions in design section 11.

Start from `0000-template.md`. ADR-0001 is reserved for the minimum git version decision (M0).
